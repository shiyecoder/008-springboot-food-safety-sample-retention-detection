# 设计系统 · 食品安全留样与检测管理系统

视觉方向：**文化绛红**。定位于单位内部业务系统，强调数据可读性、操作效率与状态辨识。
不使用巨幅英文口号、装饰光效、悬浮球、过度渐变和大面积插画；阴影只用于抽屉与弹窗。

## 1. 色彩

| 用途 | 色值 | 变量 | 使用场景 |
|---|---|---|---|
| 主色 | `#5B2533` | `--c-brand` | 顶部栏、主按钮、当前菜单、关键数字 |
| 主色深 | `#471C28` | `--c-brand-d` | 主按钮 hover、侧边栏底 |
| 主色浅 | `#7A3947` | `--c-accent` | 链接、信息提示、图表对比系列 |
| 辅助色 | `#2F6F6A` | `--c-teal` | 次级按钮、筛选选中态、普通图表系列 |
| 页面背景 | `#FAF7F5` | `--c-bg` | 主内容区背景 |
| 容器背景 | `#FFFFFF` | `--c-surface` | 表格、表单、卡片 |
| 分割线 | `#E8DFDA` | `--c-line` | 表格线、表单边框、卡片描边 |
| 正文 | `#2A2226` | `--c-text` | 主要文字 |
| 次要文字 | `#7A6E72` | `--c-text-2` | 辅助说明、表头 |
| 弱文字 | `#A2969A` | `--c-text-3` | 占位、时间戳 |
| 成功 | `#2D765C` | `--c-success` | 已完成、已通过、合格 |
| 警告 | `#B0762A` | `--c-warn` | 临期、待复核、待处理 |
| 危险 | `#A61B29` | `--c-danger` | 驳回、超时、不合格、删除确认 |

状态**不能只靠颜色**表达，必须同时显示中文标签。

## 2. 字体

- 中文：`"PingFang SC", "Microsoft YaHei", "Hiragino Sans GB", system-ui, sans-serif`
- 数字列：`font-variant-numeric: tabular-nums;` 保证表格数字纵向对齐
- 阶梯：页面标题 18/26（600）、卡片标题 14/22（600）、正文 13/22、表头 12/20（500）、辅助 12/18
- 字间距：正文 0，标题 0.2px，全大写英文标签 0.5px

## 3. 圆角 / 描边 / 阴影

| 令牌 | 值 | 说明 |
|---|---|---|
| `--r-sm` | 4px | 标签、输入框内小元素 |
| `--r-md` | 6px | 按钮、输入框、卡片、表格容器 |
| `--r-lg` | 8px | 抽屉、弹窗、登录卡片 |
| 描边 | `1px solid #E8DFDA` | 全局统一 |
| 卡片阴影 | none | 常规卡片不用阴影，靠描边区分层级 |
| 浮层阴影 | `0 8px 28px rgba(91,37,51,.14)` | 抽屉、弹窗、下拉 |

## 4. 布局栅格

- 侧边栏 220px（折叠 64px），顶部栏 56px，内容区外边距 24px
- 内容区最大宽度不限制，最小 1180px 触发横向滚动
- 卡片间距 16px；卡片内边距 16px（紧凑）/ 20px（常规）
- 表单标签统一 100–120px，单列输入 360–520px；搜索下拉框 180–240px
- 表格行高 44px，表头 40px；表头不设固定宽度

## 5. 角色视觉区分

| 角色 | 布局 | 视觉基调 |
|---|---|---|
| 留样员 | 顶部导航 + 卡片流（门户式工作台），无侧边栏 | 暖米底 + 绛红强调条，卡片化任务 |
| 检测员 | 侧边栏 + 顶栏 | 左栏绛红，检测区用青绿标识 |
| 食品安全主管 | 侧边栏 + 顶栏 | 左栏绛红，复核/处置用大号状态块 |
| 系统管理员 | 侧边栏 + 顶栏 | 同上，次级色偏中性灰，弱化业务色 |

留样员端刻意与后台端在**导航位置**上区分（顶部横排 vs 左侧竖排），使同一系统内四类角色一眼可辨。

## 6. 图表规范

- 系列色序：`#5B2533` → `#2F6F6A` → `#7A3947` → `#B0762A` → `#8C7A72` → `#2D765C`
- 网格线 `#EFE6E1`，仅横向；坐标轴文字 11px `#7A6E72`
- 环图内径 62%，中心显示总数；柱图圆角 2px，不画渐变
- 折线图线宽 2px，面积填充 8% 透明度
- 图例统一底部居中，字号 11px

## 7. 动效

- 交互反馈 120ms ease-out；抽屉滑入 220ms cubic-bezier(.2,.8,.2,1)
- 禁止页面级入场动画、禁止滚动视差
- 加载超过 300ms 显示局部骨架屏，不做整页白屏
